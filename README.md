# 🍅 番茄钟 - Pomodoro Timer

一个简单易用的番茄钟应用，帮助你专注工作，提高效率。

## ✨ 功能特点

- ⏱️ **工作/休息计时** - 标准番茄钟工作流（工作 25 分钟 / 休息 5 分钟）
- 📊 **今日统计** - 跟踪今日完成的番茄数和专注时长
- 🔔 **声音提醒** - 计时结束时播放提示音
- 📱 **系统通知** - 浏览器通知提醒
- ⚙️ **可自定义** - 自定义工作时长、休息时长、长休息间隔等
- ⌨️ **快捷键** - 按 `空格` 开始/暂停，按 `R` 重置
- 💾 **本地存储** - 设置和统计数据保存在本地
- 🖥️ **桌面应用** - 基于 Electron 打包的桌面应用

## 🚀 快速开始

### 在线使用

直接在浏览器中打开 `index.html` 即可使用。

### 安装桌面应用

1. 下载最新版本的安装包：
   - Windows 安装包（.exe）
   - Windows 便携版（.exe）

2. 运行安装程序或直接运行便携版

## 📖 使用说明

### 基本操作

- 点击 **开始** 按钮开始计时
- 按 **空格键** 快速开始/暂停
- 按 **R 键** 快速重置

### 计时流程

1. **工作时间** - 专注工作 25 分钟
2. **短休息** - 休息 5 分钟
3. 每 4 个番茄后进行 **长休息** - 休息 15 分钟
4. 循环往复

### 设置选项

- **工作时长** - 默认 25 分钟
- **休息时长** - 默认 5 分钟
- **长休息时长** - 默认 15 分钟
- **长休息间隔** - 默认每 4 个番茄后休息一次
- **启用声音提醒** - 计时结束时播放提示音
- **启用系统通知** - 浏览器通知提醒

## 🛠️ 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **桌面**: Electron
- **打包**: electron-builder
